# OSCP 2.0 JSON schemas (Open Charge Alliance)

The `.json` files here are every file of `schemas.zip` from the Open Charge
Alliance's OSCP 2.0 document set (Open Smart Charging Protocol 2.0, FINAL,
2020-10-12, <https://openchargealliance.org/protocols/open-smart-charging-protocol/>),
unmodified.

redistributed here unchanged, with this attribution; `SHA256SUMS` lists
their digests and `TestSchemasMatchSpecData` checks them. They are not
covered by this module's Apache-2.0 licence.

Do not edit these files. Where a schema disagrees with the specification
text, `schema.go` corrects it in memory when it loads the schemas; the
files stay as published.
